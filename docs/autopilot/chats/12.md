  - clay on cloud/mist is 2.74/2.53:1, used for every error, the .eyebrow (globals.css), Remove/Delete links and the Sensitive badge

- Tap targets under 44px: BillingIntervalToggle, memories Dismiss/Remove, recipient Remove (referrals), the magic-link button (AuthForm), delete account (account).

- The waitlist, invite and profile fields aren't in <form> elements, so Enter doesn't submit.
- Parent profile: no maxLength, no inline validation, success and error share one small muted line, no unsaved-changes warning.
- Memories page: no add or edit, and the error text is xs. The edit API exists from chat 4.
- Duplication: the CTA band in 6 pages, inline input classes in 5 places, status badges in family-summary and referrals, the Parent interface defined 3 times (parent-profile, onboarding, useParents.ts).
- No skip link, no not-found.tsx, no error.tsx.
- focus:ring-sage does nothing because the forms plugin isn't installed.
