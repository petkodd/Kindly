TASKS:
1. **SEO-1 (CRITICAL).** One `siteUrl()` helper in `src/lib/seo.ts`; every use of `NEXT_PUBLIC_SITE_URL` / the `dearly.example.com` fallback goes through it, including `api/billing/checkout/route.ts` and `api/billing/portal/route.ts`. `next build` fails with a clear message when `VERCEL_ENV=production` (or `NODE_ENV=production` and the host isn't localhost/127.0.0.1) and the URL is missing, not `https://`, or contains `example.`. Unit tests: missing, http, example, localhost, valid.
2. **SEO-11.** `test/seo.test.ts`: discover every route under `src/app/(public)` from the filesystem; for each: metadata exists, title ≤60, description 110–160, canonical = `siteUrl() + path`, titles and descriptions unique, page is in the sitemap XOR `index:false`. A new page without metadata must fail the test. Add `npm run seo:audit` (runs `scripts/seo-review/audit.cjs`) and document it in the README.
3. **SEO-2.** `src/middleware.ts`, production only: a request whose host isn't the canonical host (`*.vercel.app`, `www.` vs apex) → 308 to the same path and query on the canonical host. `/api/*`, cron routes and the Stripe webhook are not redirected; they get `X-Robots-Tag: noindex` instead. Preview deployments are not redirected. Existing auth redirects unchanged. Tests with mocked hosts for each case.

- Middleware tests cover canonical host, vercel.app, www, preview, `/api/*`, webhook, cron.
